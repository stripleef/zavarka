# Кофейня-кондитерская «Заварка» (г. Ишимбай)

Официальный сайт заведения «Заварка» в городе Ишимбай (ул. Бульварная, 14, 1 этаж, ТЦ «Интер»).

- **Сайт:** Кофе свежей обжарки, авторские десерты собственного производства со свежими ягодами, римская пицца и сытные завтраки.
- **Вайб заведения:** Массивные круглые столы из светлого дуба, мягкий свет светильников-чайников, картины Зазеркалья на стенах.
- **Технологии:** Чистый HTML5 / CSS3 / TailwindCSS / Векторный SVG-логотип «ЗВ».
